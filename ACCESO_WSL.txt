║  🔄 SI LA IP DE WSL CAMBIA                                           ║

La IP de WSL puede cambiar al reiniciar Windows o WSL.

SÍNTOMAS:
  • La página no carga en el navegador
  • Sale error "No se puede acceder a este sitio"
  • Pantalla blanca

SOLUCIÓN RÁPIDA:

  1. Abre Ubuntu (WSL)

  2. Ejecuta el script automático:
     ./actualizar-ip-wsl.sh

  3. El script:
     ✓ Detecta la nueva IP automáticamente
     ✓ Actualiza la configuración
     ✓ Reinicia los servicios
     ✓ Te muestra la nueva URL

  4. Espera 2-3 minutos

  5. Usa la nueva URL que te muestra el script

╔══════════════════════════════════════════════════════════════════════╗
║  🐛 SOLUCIÓN DE PROBLEMAS                                            ║
╚══════════════════════════════════════════════════════════════════════╝

PROBLEMA 1: Pantalla blanca en Windows

  Causa: La IP de WSL cambió

  Solución:
    cd /home/marcos/biblioteca
    ./actualizar-ip-wsl.sh


PROBLEMA 2: "No se puede acceder a este sitio"

  Opción A - Verificar IP:
    hostname -I | awk '{print $1}'
    Usa esa IP en el navegador

  Opción B - Firewall de Windows:
    1. Buscar "Firewall de Windows Defender"
    2. "Configuración avanzada"
    3. "Reglas de entrada" → "Nueva regla"
    4. Puerto TCP: 4000, 8090, 8081
    5. Permitir conexión


PROBLEMA 3: Sigue en inglés

  1. Espera a que cargue completamente (15 segundos)
  2. Busca selector de idioma (arriba derecha)
  3. Selecciona "Español"
  4. Si no aparece, limpia caché: Ctrl+Shift+Delete


PROBLEMA 4: Error 500

  Causa: Los servicios aún no terminaron de iniciar

  Solución:
    Espera 2-3 minutos después de iniciar/reiniciar
    Ver logs: docker logs -f dspace-angular
