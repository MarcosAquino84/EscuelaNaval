Estás usando:
  • Ubuntu en WSL (Windows Subsystem for Linux)
  • Navegador en Windows (no en WSL)

El problema:
  ❌ localhost desde Windows NO apunta a WSL
  ❌ El navegador de Windows no puede acceder a localhost de WSL
  ❌ Necesitas usar la IP de WSL en lugar de localhost

║  🐛 SI SIGUE SIN FUNCIONAR                                           ║
╚══════════════════════════════════════════════════════════════════════╝

PROBLEMA: Pantalla blanca

  Causa 1: No esperaste suficiente
  Solución: Espera 3-4 minutos completos

  Causa 2: Angular aún compilando
  Solución: docker logs -f dspace-angular

  Causa 3: Caché del navegador
  Solución: Ctrl + Shift + Delete, borra caché


PROBLEMA: Error 500

  Causa: Backend no accesible
  Solución: Verifica que backend responde
    curl -I http://172.27.72.64:8090/server/api


PROBLEMA: No se puede acceder

  Causa 1: IP cambió
  Solución: ./actualizar-ip-wsl.sh

  Causa 2: Firewall Windows
  Solución:
    - Buscar "Firewall de Windows"
    - Agregar reglas para puertos 4000, 8090, 8081


PROBLEMA: Sigue en inglés

  Solución:
    - Espera a que cargue totalmente
    - Busca selector de idioma (arriba derecha)
    - Selecciona "Español"
    - Limpia caché si es necesario
