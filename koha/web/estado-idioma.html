Koha - Sistema Bibliotecario

⚠️ IMPORTANTE

Koha NO está instalado como sistema completo.

Tu configuración actual usa archivos HTML estáticos para simular Koha, pero no incluye el sistema Koha real (Perl/CGI).

¿Qué significa esto?
  • Panel HTML: Está en español ✅
  • Sistema Koha real: No está instalado ❌
  • Base de datos: Existe pero está vacía

Para tener Koha real funcionando en español, necesitarías:

  1. Instalar imagen Docker de Koha oficial (koha/koha-testing)
  2. Configurar toda la estructura de Koha
  3. Instalar paquetes de idioma español
  4. Inicializar base de datos con esquema Koha
  5. Configurar en las preferencias del sistema

Este proceso es complejo y toma varias horas. Ver archivo SOLUCION_PROBLEMAS.md para instrucciones detalladas.

Recomendación

Para un repositorio digital, DSpace es suficiente.

DSpace ya incluye gestión de colecciones, metadatos, búsqueda, control de acceso y preservación digital. Solo necesitas Koha real si requieres gestión bibliotecaria tradicional (préstamos físicos, circulación, adquisiciones).
